# MiPix 测试方法（真机验证手册）

本文件记录 MiPix 项目的**现场测试方法**：如何在真机上触发备份、采集日志与资源数据、做参数矩阵与故障注入，以及容易踩的坑。用于复现与回归《[技术问题与方案.md](./技术问题与方案.md)》中的性能、一致性与可靠性结论。

## 1. 适用范围与原则

- 性能 / 一致性 / 可靠性类改动**必须真机验证**；`flutter analyze`、`flutter test` 只是前置门槛。
- 渐进式：先确认基线 → 单变量改动 → 同条件 A/B → 多轮取中位。
- **不弱化 fail-closed**：任何测试都不得为了「跑通」而放宽「远端 SHA-256 实读通过才 rename」。

## 2. 环境与设备

- 目标设备：Redmi K20 Pro（raphael / Android 11）。
- 应用包名：`com.chesereri.mipix`。
- 工具**不在 PATH**，统一用绝对路径：
  - adb：`E:\Code\BuildingSoftWare\android-sdk\platform-tools\adb.exe`
  - flutter：`E:\Code\BuildingSoftWare\flutter\bin\flutter.bat`
- NAS：Samba 4.19（示例 `192.168.31.184`，共享 `MyDoc`，备份根 `/MyDoc/temp/MiGallery/`）。

## 3. 设备准备

```powershell
$adb = "E:\Code\BuildingSoftWare\android-sdk\platform-tools\adb.exe"
& $adb devices
& $adb shell "input keyevent KEYCODE_WAKEUP; input swipe 500 1500 500 500 300; svc power stayon true"
```

- 必须先唤醒并解锁：MIUI 锁屏会拦截安装，也可能限制后台。
- `svc power stayon true` 防止 Doze 限速。

## 4. 构建与安装

```powershell
& "E:\Code\BuildingSoftWare\flutter\bin\flutter.bat" build apk --release   # 禁沙箱，否则易静默卡死
& $adb install -r app\build\app\outputs\flutter-apk\app-release.apk
```

- **签名一致**时 `-r` 覆盖安装保留数据（SMB 配置、已同步集合）；签名变化会清空应用数据，需先提醒用户备份。
- 每次改动后核对 APK 时间戳 ≥ 代码改动时间，避免「装着旧包测新逻辑」。

## 5. 触发与 UI 自动化

- 拉起应用：`monkey -p com.chesereri.mipix -c android.intent.category.LAUNCHER 1`
- 取控件坐标：`uiautomator dump /sdcard/ui.xml` → `adb pull` → 解析 `content-desc` 与 `bounds`
- 点击：`input tap X Y`
- 常用坐标（1080×2340 分辨率）：底部 Tab「照片 303 / 相册 491 / 传输 727 / 更多 1009，y=173」；「全部备份」(898,382)；「重试失败」按钮随列表浮动，每次重新 dump 取 `bounds`。
- 传输页文案可作状态断言：`未同步 共 N 张`、`重试失败 N`、每个任务的「完成 / 失败」。

## 6. 日志采集与解析

```powershell
& $adb logcat -v time -s flutter      # 后台持续采集到文件
```

- 阶段打点：`[backup][stage] task=... phase=<phase> remote="<path>" bytes=<n> ms=<n> mbps=<n>`
  - `phase` ∈ preparing / uploading / localHash / verifying / finalizing / rename / setFileTime
  - **注意**：`_logStage` 记录的是「刚结束」的阶段，当前阶段 = 紧随其后的那条。
- 校验打点：`[backup][verify] START remote=... ranges=N concurrency=N` / `range OK ...` / `OK|FAIL|SIZE MISMATCH|INCOMPLETE`。
- `remotePath` 形如 `<相册名>/<文件名>`（如 `MiPixFITest/fit_a.mp4`），按**文件名子串**匹配即可，不要按纯文件名匹配。
- 关键判定：出现 `phase=rename remote="..."` 才算真正落盘成功；`verify FAIL` 且全程无 rename 即 fail-closed 生效。

## 7. 参数矩阵测量法（单文件运行时开关）

- 把被测参数写入应用**私有目录**下的一个文本文件（如 `.../files/mipix_measure.txt`，内容 `upload=4 verify=0`），代码在每任务开始时读取一次。**一次构建即可跑完整矩阵**，省去反复构建。
  - 这是**临时测量手段**：测完必须删除该 shim 及全部引用，避免污染发布版。
- 切换档位：
  ```powershell
  & $adb shell "echo 'upload=4 verify=0' > /storage/emulated/0/Android/data/com.chesereri.mipix/files/mipix_measure.txt"
  ```
- 触发一轮备份 → 等待 `phase=finalizing` → 记录该档三条耗时。

## 8. 资源采样

- CPU（进程总占用）：
  ```powershell
  & $adb shell "top -b -n 2 -d 1"
  ```
  在 PowerShell 侧**筛选行尾为包名**的行再取最后一条：
  ```powershell
  ($out | Select-String 'com\.chesereri\.mipix\s*$' | Select-Object -Last 1)
  ```
  **坑**：直接 `grep mipix` 会把 `sh` / `grep` 自身命令行也匹配进来，导致 CPU 恒为空或 0。
- 内存：`dumpsys meminfo <pkg>` 取 `TOTAL PSS`，观察是否随并发增长。
- 连接数：`netstat -tn | grep :445`（含僵死连接，需结合有无流量判断）。

## 9. 媒体可见性（让新测试文件被相册识别）

- 建测试文件后需入库 MediaStore。单文件扫码广播**对既有目录可能不生效**（实测无效）：
  ```powershell
  & $adb shell "am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE -d file:///storage/emulated/0/DCIM/<dir>/<file>"
  ```
- 若相册里看不到，**重启手机会触发全量媒体扫描**（实测有效）；重启后重新解锁 + `stayon` + 拉起应用。

## 10. 故障注入

- 网络中断（等价断网 / 服务端瞬断）：
  ```powershell
  & $adb shell "svc wifi disable"    # 注入
  & $adb shell "svc wifi enable"     # 恢复
  ```
  可在**上传段**或**校验段**中途注入；恢复后走「重试失败」验证可恢复性。
- 服务端侧（需 NAS 权限）：重启 Samba 服务、手动删除孤儿 `.mipixtmp`、或制造短读（少发字节）——用于覆盖「停服务」「短读」场景。

## 11. 数据口径与统计

- 每档跑 **≥3 次取中位**，抵御环境漂移（同一 45 分钟窗口内可能出现 15%~20% 的吞吐整体下滑）。
- 多档对比用**交错顺序**（如 2,4,6,8,4,2,…）进一步抵消漂移。
- 采样时间统一用**设备时间**（`adb shell date`），主机与设备时钟可能差几秒。
- 结论中明确标注绝对值带系统性偏差，以及**未覆盖的判据**。

## 12. 常见坑速查

| 现象 | 原因 | 规避 |
|---|---|---|
| 装了新功能却没生效 | APK 早于代码改动 | 比对 APK 时间戳，必要时 `-r` 重装 |
| CPU 采样恒为空 / 0 | `grep mipix` 自匹配（含 `sh`/`grep` 进程行） | 改为「行尾匹配包名」再取最后一条 |
| 新测试文件相册看不到 | 单文件扫码广播未生效 | 重启手机触发全量扫描 |
| `verify FAIL` 但 `range OK` | 乱序块缓冲被复用缓冲区覆写（已修复） | 保留「需要延后使用的块才复制」的回归测试 |
| 重试某文件长时间无日志 | 服务端锁未释放、setup 调用无超时（缺陷，见技术文档 13.11） | 重启 Samba / 删除孤儿 `.mipixtmp` |
| release 构建无输出卡死 | Windows 命令沙箱 | 构建时禁沙箱 |
| 安装被 MIUI 拦截 | 锁屏 | 先唤醒解锁 |

## 13. 收尾清理

```powershell
& $adb shell "rm -rf /storage/emulated/0/DCIM/<测试目录>; rm -f /storage/emulated/0/Android/data/com.chesereri.mipix/files/mipix_measure.txt"
```

- 同时清理 NAS 上 `temp/MiGallery/` 下的测试相册（测试会累积大量 MB 级文件）。
- 删除临时测量 shim、临时日志与脚本，保证仓库只留正式代码。
